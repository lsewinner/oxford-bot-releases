# Oxford Bot desktop installers

This repository only holds the installers of the Oxford Bot desktop app for macOS and Windows.
Each version is a release here, published automatically when the app is built.

**To download the app, go to https://oxford.bot/download**

Installed apps update themselves, so there is normally no need to download a newer version by hand.

The files in a release:

| File | What it is |
|---|---|
| `Oxford-Bot-mac-arm64.dmg` | Mac installer, Apple silicon |
| `Oxford-Bot-mac-x64.dmg` | Mac installer, Intel |
| `Oxford-Bot-windows-x64.exe` | Windows installer |
| the same with a version number, `.zip`, `.yml`, `.blockmap` | used by installed apps to update |

The Mac app is signed by OXFORD INTELLIGENCE LIMITED and notarized by Apple. The Windows installer is
not code-signed yet.
